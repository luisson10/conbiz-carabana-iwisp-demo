# Local Conbiz Demos

Mobile-first local media player for Conbiz conversational-agent demos.

## Local development

```bash
npm install
npm run dev
```

## LAN demo mode

Connect the Mac and Android devices to the same local Wi-Fi router, then run:

```bash
npm run dev:lan
```

Open the shown Network URL from each Android device, for example:

```text
http://192.168.8.123:5173
```
